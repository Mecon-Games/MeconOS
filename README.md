# Mecon OS
Neon-Betriebssystem im Browser (HTML/CSS/JS, PWA). Fokus: Handy.
1. Alle Dateien in ein GitHub-Repo hochladen, GitHub Pages aktivieren.
2. Das Handy öffnet die Seite → „Als App installieren“ (Vollbild, eigene Leisten).
3. Updates: neues Release mit Tag (z. B. v1.1.0) anlegen. In den Einstellungen Repo „Benutzer/Repo“ eintragen → „Nach Updates suchen“.
Version in os.js (VERSION), version.json und sw.js (V) anpassen.
